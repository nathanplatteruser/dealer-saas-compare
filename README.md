# Dealer SaaS click-board

Interactive compare of Beakon (lot GPS / recon; likely "Lot Beacon"), LotPilot, LotDesk, Aerolot, CARVID, Quantum Connect.

**Not a Nathan product.** Dealership SKU stays out. Marketplace Copilot + SettleUp only.

Open `index.html` on iPhone or Chrome. Tap chips, drag price slider, open sales pages.
